# compare_toolkit
Macro-suite for summarizing differences between SAS© datasets in usable table outputs. Provides all observations and variables unique to one dataset, side-by-side comparisons of differing variable values, and a consolidated discrepancy summary table for whole directories. Can be adjusted to your needs (NOT a perfectly developed &amp; tested software!)


 Edit setup.sas and enter the path where you stored the compare toolkit where the comment in the program indicates.
 Run setup.sas.
 Now you can use the wrapper macro %compare for single dataset comparisions or the macro %compare_directory to consolidated discrepancy summary table for whole directories.
 See the respective .sas files for explanations of the parameters.
 The rest of the macros are utility macros. They are only of interest to you if you want or need to make changes to the toolkit.
